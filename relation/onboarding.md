# 入职流程工作手册

## 核心理念

入职流程的核心是**从"完成手续"到"进入状态"**——不是把入职材料填完就结束了，而是让新人在最短时间内理解自己在做什么、跟谁配合、怎么上手。入职做得好不好，决定了新人前三周是"在创造价值"还是"在制造困惑"。

## 标准流程

### 第一步：入职确认

**确认双方准备就绪，再发正式 offer。** 不要给了 offer 才发现系统没开通、电脑没到位。

| 维度 | 标准 | 排除条件 |
|------|------|---------|
| 薪资待遇 | 双方确认金额、发放方式、试用期条款 | 有未澄清的待遇分歧 |
| 合同状态 | 合同已签署或明确签署时间 | 合同条款未达成一致 |
| 岗前准备 | 办公设备、开发环境、系统权限已就位 | 硬件或系统有未解决的依赖（如等待采购） |
| 时间对齐 | 双方对齐入职日期和首日安排 | 入职时间与团队重要节点冲突 |

**操作：** HR 在发出正式 offer 前，拉通用人部门确认以上四项全部就位。

**验收标准：**
- [ ] 薪资待遇双方书面确认
- [ ] 合同已签署或排期确认
- [ ] 设备/系统/权限已就位
- [ ] 入职日期与首日安排双方对齐

### 第二步：职级定级与岗位分配

**录用后，根据候选人的能力水平和岗位要求，确定其序列与等级、归属部门、具体岗位，以及直接上级。**

#### 职级定级

对照五序列职级体系确定其序列与等级：

- **G序列**（增长）— 客户获取、营收增长
- **P序列**（业务）— 业务交付与维护
- **F序列**（职能）— 职能支持与管理效率
- **T序列**（技术）— 技术研发与专业攻坚
- **M序列**（管理）— 全局统筹管理

等级从 L0（见习）至 L5（首席），具体等级由 HR 与用人部门协商确定，作为定薪与后续晋升的基准。

#### 岗位与汇报关系

确定新成员的归属部门、具体岗位，以及直接上级。汇报关系遵循辅助性原则——下级在上级无法给出清晰判断时独立决策，上级承担主要责任。

**验收标准：**
- [ ] 职级序列与等级已确定
- [ ] 归属部门与具体岗位已明确
- [ ] 直接上级已确认
- [ ] 汇报关系已说明

### 第三步：环境搭建

**让新人第一天就能正常开展基础工作。** 系统权限开通要在入职前完成，不要让新人第一天就在"等权限"。

```
系统权限清单：
├── 飞书（公司组织架构 + 相关群组）
├── 企业邮箱
├── 公共邮箱（按岗位需要：新媒体运营、HR等）
├── 代码仓库（按项目分配）
├── 文档平台
├── 项目管理看板
├── 业务系统（按角色：公众号运营者、人事管理员等）
└── 开发环境（按技术栈配置）
```

**验收标准：**
- [ ] 飞书账号已开通，加入组织架构
- [ ] 企业邮箱已开通，确认命名规范
- [ ] 必要公共邮箱权限已开通
- [ ] 代码仓库/文档平台可正常访问
- [ ] 开发环境可正常运行

### 第四步：团队接入

**新人第一天认识的不是座位，是人。** 目标是让新人知道"有事找谁"而不是"有事问谁"。

```
团队对接人清单：
├── HR 对接人 → 薪酬、制度、福利
├── 技术导师 → 技术问题、代码规范、技术决策
├── 直属上级 → 工作安排、目标设定、绩效反馈
└── 对接人 → 具体工作相关的协作方
```

**不要做的：**
- 不要第一天就让新人自己看文档（先带人再给文档）
- 不要一次性拉进所有群（先加必要群，其他按需加）
- 不要让新人自己猜"谁负责什么"（给一份明确的对接人清单）

**验收标准：**
- [ ] 直属上级已带新人认识团队成员
- [ ] 对接人清单已给到新人（HR对接人、技术导师、直属上级、协作对接人）
- [ ] 新人已加入团队日历和项目看板
- [ ] 团队协作方式（周会、日报、异步协作等）已说明

### 第五步：入职培训

**培训分三层，各司其职。** 不是所有培训都让 HR 做，也不是所有培训都甩给用人部门。

**HR 部门负责：**
- 薪资待遇说明
- 制度规范宣导（章程、手册体系）
- 团队协作格式培训
- 议事规则培训——确保新人理解公司协作决策方式
- 交接汇报链条说明

**所属部门负责：**
- 部门职责与分工介绍
- 当前主要工作与项目背景
- 新人的具体分工安排
- 需要接手的工作清单与交接
- **笔试产出落地**：如通过笔试入职，将其工作蓝图或改写稿作为第一个工作起点

**发展路径规划：**
结合新成员的发展意向和公司需求，初步规划其职业发展通道，明确当前序列内的成长路径以及未来可能的跨序列发展方向。

**自学材料：**
- 使用第二大脑资料作为入职考核和学习材料
- 新人通过自学资料快速掌握标准，按标准干活
- 换人不换标准，换标准就统一改文本

**验收标准：**
- [ ] HR 培训已完成（制度、协作、议事规则）
- [ ] 部门培训已完成（职责、分工、工作交接）
- [ ] 笔试产出落地方案已明确
- [ ] 第二大脑资料已提供给新人

### 第六步：首周跟进

**入职培训结束不是结束，新人能在无人指导下完成任务才是。** 首周保持高频低强度的跟进节奏。

```
首周跟进节奏：
├── 第 1 天：确认环境就绪 + 午餐/团队破冰
├── 第 2 天：了解新人首日感受，解答困惑
├── 第 3 天：确认第一个小任务完成情况
├── 第 4 天：了解学习进度，收集困难
└── 第 5 天：首周回顾，确认下周计划
```

**不逼问"适应得怎么样"——** 给空间，同时给明确的求助通道。

**验收标准：**
- [ ] 第 3 天确认第一个小任务完成或进展
- [ ] 首周结束有明确的第二周工作计划
- [ ] 新人明确知道遇到问题找谁

## 全流程检查清单

- [ ] 入职前准备全部就绪？
- [ ] 系统权限全部开通？
- [ ] 团队对接人明确？
- [ ] HR 培训完成？
- [ ] 部门培训完成？
- [ ] 首周跟进按节奏执行？
- [ ] 新人已可独立完成基本任务？
