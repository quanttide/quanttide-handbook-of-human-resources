# 考核原则

**聚焦实际能力**：考核题目应聚焦岗位核心能力，避免形式化官僚考察。

以新媒体运营为例，核心能力是选题和写作。考察重点是能否从原始内容中找到好的叙事角度，并邀请相关人员从多视角讲述故事。

**透明化标准**：考核标准应在招聘前明确：
- 提前告知候选人考察方向
- 试题与岗位实际工作高度相关
- 评分标准公开可解释

## 笔试题设计

设计要点：
1. 来源于实际工作：从岗位实际任务中提炼考核点
2. 考察解决问题的能力：而非知识记忆
3. 提供必要素材：如写作素材、案例材料等
4. 结果导向：要求候选人提出有效方案，而非仅批评现状

示例：新媒体运营笔试题——提供若干原始实录内容，要求候选人从中选择可写作题目，并说明选择理由和写作角度。重点考察能否提出可执行的解决方案。

## 结果判定

- 能直接做出来的 → 直接录取
- 做不出来但有成长空间 → 实训模式
- 什么都做不出来的 → 建议转岗

高信任度的同学可直接对接未来要配置的岗位。
