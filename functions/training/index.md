# 培训与开发

## 核心思想

培训与开发的核心思想，总结自公司核心成员培养实践：**以真实业务为教材，授之以渔，在容错空间中让员工完成从执行、到思考、再到带人的角色跃迁。**

### 一、以真实业务为教材

培训不脱离业务，工作本身就是课堂：客户建档、报价、谈判、预算、交付，真实任务自带压力与反馈；被拒绝的客户、返工的报价单、出问题的交付，是最好的教案。

### 二、授之以渔：教思维，不教结论

给框架、给方法，用提问代替直接给答案：

- 报价三段式：多少价格 / 为什么这个价格 / 接下来干啥；
- 预算三步法：整体够不够用 / 哪些可争取可砍 / 解决不了借多少；
- 四问汇报框架：沟通了什么 / 达成什么共识 / 接下来做什么 / 可能遇到什么困难。

管理者把自己当作教材，把思维过程显性化，供下属观察、模仿、内化。

### 三、渐进式授权：让员工执行自己的想法

示范（范例）→ 执行自己的想法 → 逐步接手。试用期主线任务兼具业务价值与学习功能；在容错空间内试错，管理者负责兜底。失败是常态，质量是底线。

### 四、AI 是思考的脚手架，不是替代

"不要发 AI 原文，说你自己复述的结果。"AI 可以协助梳理，但结论必须经过自己的消化与复述——防止人变成转述工具，训练独立思考。

### 五、培养的终点是"教别人干"

从"自己干"到"会教别人干"，是每一级晋升的验收标准。个人经验只有沉淀为手册、清单、制度，才真正属于组织，不随人员流动而流失。

### 六、按阶段一人一策

新人重思考习惯，骨干重经营意识，高管重机制建设；同一套方法不能同时用于新人和高管，节奏不可颠倒。批评直接但给方法，责任有边界。

> 注：核心思想总结自公司人才培养实践案例（详见案例集培训目录），用于指导培训的内容设计、带教安排与晋升考核。
